# Todo-Ding-App

A simple web-based to-do list app to add, complete, and delete tasks. Built with HTML, CSS, and JavaScript.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Clean, responsive UI

## Installation
1. Clone the repo:
```bash
git clone https://github.com/sharanya1533/todo-ding-app.git
Open index.html in a browser (or use Live Server).

Usage

Type a task and press Enter or click "Add"

Click checkbox to mark complete

Click delete icon to remove
